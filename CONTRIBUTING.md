Contributing Guide

Before submitting PRs:
- Ensure you are authorized to contribute the content.
- Provide metadata for every tool or playbook added:
  - name
  - category (redteam / blueteam / infra / playbook)
  - short description (1-2 lines)
  - tested OS/version
  - intended use (lab / incident response / production)
  - upstream links and license
- Add a short, sanitized example of usage and harmless test data where applicable.

PR checklist
- [ ] Follows scope & rules in `README.md`.
- [ ] Includes a responsible-use statement.
- [ ] Has at least one reviewer with domain expertise.
